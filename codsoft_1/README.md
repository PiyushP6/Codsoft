## Objective
Predict whether a passenger survived the Titanic disaster using machine learning.

## Dataset
Titanic-Dataset.csv

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

3. Data preprocessing
4. Handle missing values
5. Encode categorical data
6. Split the dataset
7. Train the model
8. Evaluate performance

- Logistic Regression

## Evaluation Metrics
- Accuracy
- Precision

- F1 Score
