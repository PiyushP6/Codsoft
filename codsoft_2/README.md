# 🎬 Movie Rating Prediction with Python

## 📌 Project Overview

This project builds a Machine Learning Regression model to predict the rating of a movie based on features such as genre, director, actors, duration, votes, and year.

The project demonstrates the complete Data Science workflow, including data preprocessing, feature engineering, model training, evaluation, and prediction.

---

## 📂 Dataset

Dataset: IMDb_Movies.csv

The dataset contains information about movies, including:

- Movie Name
- Genre
- Director
- Actors
- Duration
- Year
- Votes
- Rating

---

## 🎯 Objective

Develop a regression model capable of predicting movie ratings accurately using historical movie data.
